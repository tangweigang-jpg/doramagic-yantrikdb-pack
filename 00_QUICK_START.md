turn yantrikdb into an AI memory governance pack with contradiction checks, decay boundaries, recall evals, and recovery rules for polluted agent memory

## Two-Minute Path

1. Read `AGENTS.md`.
2. Copy the relevant host instruction into your AI coding host.
3. Run `06_EVALS/smoke_check.md`.
4. If the check fails, open `03_PITFALL_LOG.md`.
